# 小玲 (XiaoLing) - 主动陪伴机器人 🤖💗

> **你提需求，我来搞定。尤其是那些你一直拖着不想做的事。**

小玲是一款**本地运行、隐私友好**的主动陪伴助手。它会"盯"着你在电脑上的使用情况，在你刷视频太久、深夜 emo、注意力涣散时，温柔地出现在你面前，陪你聊两句、给你建议，帮你找回状态。

灵感来自抖音上的"主动陪伴机器人"：你说一声 **"开启主动陪伴"**，小玲就会调用摄像头看看你、帮你打开网易云 / 抖音 / B 站这些平台，然后根据你观看的时长和停留的时间，**动态判断你的心情**，并给予陪伴和解决方法。

## ✨ 它能做什么

| 能力 | 说明 |
|---|---|
| 🎥 **开启主动陪伴** | 说出或点击"开启主动陪伴"，小玲启动摄像头预览 + 开启后台监控 |
| 🚀 **帮你打开平台** | 一键打开网易云 / 抖音 / B 站（优先桌面客户端，找不到自动回退网页版） |
| 📡 **窗口监控** | 每 2 秒检测你当前正在用哪个平台、停留了多久 |
| 🧠 **心情判断** | 基于停留时长 + 时间段 + 平台 + 切换频率，并融合**摄像头表情识别**信号，推断你的心情状态 |
| 😊 **表情识别** | 摄像头开启后，用浏览器前端 AI 识别你的表情（开心/难过/生气…），数据不出本机，作为心情判断依据 |
| 💬 **温柔陪伴** | 匹配预设话术库，用对话气泡给你陪伴建议 |
| 📅 **陪伴日志** | 记录每次陪伴事件，保存到本地，随时回看 |

### 心情判断规则示意

| 触发条件 | 心情状态 | 小玲回应方向 |
|---|---|---|
| 深夜 23 点后 + 抖音 > 40 分钟 | 🌙 深夜 emo 刷手机 | 温柔劝睡、放下手机 |
| B 站 > 1h + 频繁切换 | 😶 无聊打发时间 | 推荐专注或起身活动 |
| 网易云长时间播放 | 🎧 听歌沉浸 / 可能低落 | 陪伴倾听、轻建议 |
| 短时间多平台跳跃 | 🌀 注意力分散 / 焦虑 | 引导深呼吸、整理思绪 |
| 长时间无操作 | 🥱 发呆 / 疲惫 | 关心询问、建议休息 |
| 表情 = 难过 / 生气 / 害怕 | 😢 低落倾诉 / 😠 烦躁 / 😨 不安 | 优先响应情绪，倾听陪伴、情绪疏导 |

> 💡 表情识别信号**优先于**时长规则：当你露出难过/生气/害怕的表情时，小玲会第一时间关注你的情绪，而不是只看刷了多久。开心/平静等表情不作干扰，仍按使用时长判断。

## 🧱 它怎么实现

**技术架构：Web 前端 + Python 后端**，全程本地运行、零云端依赖。

```
┌─────────────────────────────┐
│   前端 (HTML+CSS+JS)         │
│   · 小玲界面 / 摄像头预览     │
│   · 陪伴对话流 / 平台入口     │
└────────────┬────────────────┘
             │ REST API (localhost:7788)
┌────────────▼────────────────┐
│   Python 后端 (FastAPI)      │
│   · monitor.py  窗口监控轮询  │
│   · launcher.py 启动平台应用  │
│   · mood_rules.py 心情规则引擎│
│   · companion_data.py 话术库 │
└─────────────────────────────┘
```

### 核心流程

```
开启主动陪伴
   → 前端开摄像头预览 + 通知后端启动监控
   → 后端每 2 秒轮询前台窗口 (GetForegroundWindow)
   → 识别所在平台 + 累计停留时长
   → 规则引擎判断心情状态
   → 前端弹出小玲陪伴语 + 建议
   → 记录到陪伴日志
```

### 关键技术点

- **窗口监控**：`pywin32` 调用 `GetForegroundWindow` 获取前台窗口标题，通过关键词匹配识别平台
- **平台启动**：`subprocess` 启动桌面端，找不到桌面端则回退打开网页版
- **心情规则引擎**：纯规则逻辑，无模型依赖，秒级响应
- **本地存储**：前端 `localStorage` + 后端 JSON，不经过网络

### 项目结构

```
小玲/
├── app.py              # FastAPI 后端入口
├── monitor.py          # 窗口监控模块
├── launcher.py         # 平台启动模块
├── mood_rules.py       # 心情规则引擎
├── companion_data.py   # 陪伴话术库
├── requirements.txt    # Python 依赖
├── start.bat           # 一键启动脚本 (Windows)
└── static/
    ├── index.html      # 前端界面
    ├── style.css       # 暗色陪伴风样式
    └── app.js          # 前端逻辑
```

## 🚀 快速开始

> 仅支持 Windows（依赖 pywin32 窗口监控）。

### 方式一：一键启动（推荐）

1. 安装 [Python 3.9+](https://www.python.org/downloads/)
2. 双击 `start.bat`
3. 浏览器自动打开小玲界面 → 点击"开启主动陪伴"

### 方式二：手动启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动后端
python app.py

# 3. 打开浏览器访问
http://localhost:7788
```

## ✨ (可选) 开启 AI 个性化陪伴

默认使用预设话术库回应。想让小玲根据你的心情**动态生成**更个性化的回复，只需配置一个大模型 API Key（默认接入 DeepSeek，OpenAI 兼容接口，也可切换其他厂商）：

```bash
# Windows PowerShell 临时设置（当前窗口有效，重开窗口需重设）
$env:XIAOLING_AI_API_KEY="sk-你的-key"
$env:XIAOLING_AI_BASE_URL="https://api.deepseek.com/v1"   # 可切换其他兼容供应商
$env:XIAOLING_AI_MODEL="deepseek-chat"
python app.py
```

> 🔑 在 [DeepSeek 开放平台](https://platform.deepseek.com) 注册可获取 Key。
> 未配置 Key 或调用失败时，小玲会**自动回退**到内置话术库，流程不中断。

### 环境变量说明

| 变量 | 默认值 | 说明 |
|---|---|---|
| `XIAOLING_AI_API_KEY` | 空 | API Key；留空则禁用 AI，走预设话术 |
| `XIAOLING_AI_BASE_URL` | `https://api.deepseek.com/v1` | OpenAI 兼容接口地址 |
| `XIAOLING_AI_MODEL` | `deepseek-chat` | 模型名 |
| `XIAOLING_AI_TIMEOUT` | `15` | 请求超时（秒） |

## 🛠️ 常见问题

**Q：摄像头开不了？**
A：首次使用浏览器会请求摄像头权限，请点击"允许"。小玲仅在本机预览，不发送任何画面数据。

**Q：监控不到我打开的平台？**
A：确保是通过小玲的"平台入口"按钮打开的（这样窗口有对应标题）。也可检查防火墙是否放行本机 7788 端口。

**Q：用什么浏览器？**
A：推荐 Chrome / Edge，对 `getUserMedia` 支持最好。
